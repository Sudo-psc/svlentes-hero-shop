## 🏆 MELHORES PRÁTICAS

### Conteúdo
✅ Responda diretamente a pergunta logo no início  
✅ Use listas e bullet points para escaneabilidade  
✅ Limite técnico: 150-300 palavras por resposta  
✅ Inclua CTA relevante em cada resposta  
✅ Use linguagem natural (como paciente perguntaria)  

### Técnico
✅ Schema markup válido e sem erros  
✅ Um FAQPage schema por página  
✅ Máximo 10 FAQs por página  
✅ URLs amigáveis e descritivas  
✅ Internal links estratégicos  

### SEO
✅ Otimize title e meta description  
✅ Use H2 para perguntas, não H1  
✅ Adicione schema também no blog  
✅ Monitore featured snippets conquistados  
✅ A/B test diferentes formatos de resposta
